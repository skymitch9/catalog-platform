Operations

Run controls — devops and approvers only.

    Ingestion — pause & resume

    Stops and starts the ingestion process flow on the home machine. There are three ways to pause: Pause until I unpause… (nothing but Resume ends it), Pause for now and Pause until… — the last two end themselves as soon as the GPU has been quiet for about four minutes, or when the 12am window opens, whichever comes first. Every control here takes two taps: the others arm and then confirm, while Pause until I unpause… asks what the pause should mean and the answer you pick is the confirmation. Every time on this card is read as Phoenix time.

    Reading the ingestion control…

    At latest. This is the longest it can last, not a promise: it also ends as soon as the GPU has been quiet for about four minutes, or when the 12am window opens — whichever comes first. Use Pause until I unpause… if it has to survive all three.

    Recurring blockers

    Standing weekly quiet hours — Mon Tue Wed, 6:30 PM – 10:15 PM, say. A blocker is absolute while it is in force: no GPU reading releases it, a “Pause for now” does not outrank it, and it beats the scheduled 12am–8am window for any hours they overlap. To block an evening into the next morning set the end earlier than the start (10:00 PM to 2:00 AM). Times are Phoenix time.
